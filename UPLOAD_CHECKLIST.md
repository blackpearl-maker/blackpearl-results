# Upload Checklist

- [ ] Every frozen artifact has a corresponding SHA-256 hash.
- [ ] Every manifest lists inputs, outputs, and hashes.
- [ ] README links to VALIDATION, RESULTS, METHODOLOGY, REVIEW_REQUEST.
- [ ] No source code included.
- [ ] No equations included.
- [ ] No internal algorithmic logic included.
- [ ] No raw sensitive customer data included.
- [ ] Wording of results and claims is strictly unmodified.
